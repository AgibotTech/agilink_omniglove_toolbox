# OmniGlove Toolbox v1.0.0 快速入门

[English](../en/QUICK_START.md) · [返回首页](../../README_zh_cn.md)

## 1. 安装并连接

按平台安装 [Linux 包](../../linux/x64/README_zh_cn.md)或 [Windows 包](../../windows/x64/README_zh_cn.md)，然后启动 OmniGlove Toolbox。安装包自带所需应用运行库和仿真环境。

接入手套，在 **设备设置** 中查看已识别设备的 SN、手别与版本，点击对应设备的 **连接**，也可使用 **连接所有设备**。未识别到设备时点击 **重新识别**。同侧多设备时，在数据视图中按 SN 选择来源。

有触觉版本在首次收到有效触觉数据及每次重连后自动置零，请保持手套无接触 **2 秒**。无触觉版本可直接使用姿态和模型功能。

## 2. 查看实时数据

| 页面 | 用法 |
| --- | --- |
| **触觉分布** | 查看左右手触觉点位与趋势曲线；需要重新建立基准时点击 **压力置零**，并保持无接触 2 秒。0–255 是传感器触觉值，灰色表示无数据。 |
| **手部模型** | 拖动旋转、滚轮缩放；可选择手别、触觉点位、手腕姿态和关节角详情。默认显示 SDK POST，勾选 **抗磁对比** 可并排查看 POST 与上位机 POSE 解算。 |
| **运动轨迹** | 查看五指在腕部坐标系中的关键点、姿态轴和局部轨迹；坐标单位为毫米，腕部固定在原点。 |
| **日志** | 查看设备连接及操作日志，可按级别、来源或关键词筛选。 |

## 3. 六动作个人标定

进入 **标定**，选择目标手和标定根目录，点击 **开始标定**，依次跟随界面提示：

1. 四指并拢伸直，保持静止。
2. 四指根部弯曲，再伸直，连续完成两次；其余指节保持伸直。
3. 拇指与食指指尖轻触并保持稳定。
4. 拇指与中指指尖轻触并保持稳定。
5. 拇指与无名指指尖轻触并保持稳定。
6. 拇指与小指指尖轻触并保持稳定。

换对指动作前先完全松开，等待下一条提示。查看有效样本、质量与拟合结果；结果保存后点击 **写入手套**，等待写入及读回校验通过。**只完成采集或保存文件，新标定尚未生效。**

已有 `.ogcal` 文件可通过 **导入已有标定** 选择。导入只检查文件；确认目标手后仍需点击 **写入手套**。左右手分别标定、分别写入。

## 4. 录制与回放

在数据视图点击 **录制并保存** 并选择文件，结束时点击 **停止并保存**，生成 `.ogrecord`。需要动作文件时勾选 **同时导出 BVH**。

点击 **打开录制** 可离线播放、暂停及拖动进度；触觉、模型和指尖视图同步回放。结束后点击 **返回实时**，再进行实时录制、标定或固件操作。

## 5. 遥操作

进入 **遥操作**，选择 OmniHand 2025（O10）、OmniHand 3 Ultra（T1.3 / T1.5）或 OmniHand 3 Lite，配置左手、右手或双手。

- **模拟仿真**：连接相应手套后点击 **开始遥操作**，自动打开 MuJoCo 窗口；无需连接机器人或额外安装 Python。停止遥操作会关闭仿真窗口。
- **连接实机**：选择实际连接方式，并填写对应的设备 ID、CAN 通道、网口或串口参数，再开始遥操作。双手使用对应手别；CAN 适配器使用不同通道或适配器，串口使用不同路径，同一 SocketCAN 接口需不同设备 ID。首次使用可在高级设置中降低关节限速。

**手套输入录制与回放** 面板可将当前遥操输入保存为 `.ogteleop`。打开动作文件后，可重新解算并在仿真或实机中回放，无需连接手套；实机回放仍需连接机器人。

## 6. 固件升级

先停止录制、退出回放并结束其他任务。在 **固件升级** 页刷新设备，核对设备身份和当前版本；选择 **主控**、**节点** 或 **节点 + 主控**，载入对应正式 BIN/HEX 固件并校验，确认目标及版本后开始写入。

联合升级先写节点再写主控。写入开始后不可取消或关闭应用，期间保持供电与 USB 连接。多设备或 DFU 模式下按 USB 位置确认目标。本仓库的上位机安装包不包含设备升级固件。

遇到问题见[故障排除](TROUBLESHOOTING.md)。
